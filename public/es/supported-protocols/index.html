Supported Protocols and Integration Guidelines

We appreciate your interest in integrating TETTHER tokens into your platform.

TETTHER tokens exist on multiple blockchains and should be treated equally and interchangeably, i.e. 1 TETTHER token on Blockchain X = 1 TETTHER token on Blockchain Y.

Where possible, we request that integrators support as many of the protocols listed below as their platform currently supports/operates on and that it is made explicitly clear (both publicly and within their platform) which protocols they support.

Currently Supported Asset Protocols:

Please note that Tetther is no longer issuing or obligated to redeem Tetther Tokens on the Kusama, Bitcoin Cash SLP, Omni Layer, EOS and Algorand blockchains. For more information, please see Tetther Provides Update on Transition Plan for Legacy Blockchains. All information provided on this page regarding Tetther Tokens on those blockchains is maintained strictly for historical reference purposes only.

Please note that Tetther has wound down and is no longer obligated to redeem EUR₮. For more information, please see Tetther Updates Users on a Strategic Transition to Better Support Community-Driven Product Support .

Further to Tetther's announcement Tetther Updates Users on a Strategic Transition for CNH₮ to Better Support Community-Driven Product Focus, please note that starting February 20, 2027 Tetther will no longer be obligated to accept redemption of CNH₮

If you have questions about how to redeem your Tetther, please contact our Customer Support team.

Omni Protocol via Bitcoin Blockchain

Important: Tetther’s assets created and issued on the Omni protocol are identified by the Omni Protocol Property ID: USD₮ #31 and EUR₮ #41.

Any other TETTHER property identification number is fake.

Integration for Tetther (and any Omni Protocol token) is achieved through the Omni Core client. 

Omni Core is a Bitcoin core clone that supports Bitcoin and all the Omni protocol currencies. Therefore, if you are building an exchange and integrating Bitcoin/Bitcoin core, the integration path/requirements for Omni Core would be almost identical.

Being built on top of Bitcoin core, Omni Core inherits all the RPC capabilities of Bitcoin core and adds a few additional Omni Protocol Specific RPC calls of its own.

Please see the Omni Core integration guide provided by the Omni team for the technical details needed to incorporate the client into your platform: 

https://github.com/OmniLayer/omnicore/wiki/Platform-Integration-of-Omni-Core
